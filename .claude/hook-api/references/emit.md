# Emit API

API for transaction emission. Used when issuing new transactions from a Hook.

## emit

Emit a constructed transaction.

```c
int64_t emit(uint32_t write_ptr, uint32_t write_len, uint32_t read_ptr, uint32_t read_len);
```

**Parameters:**
| Name | Type | Description |
|------|------|-------------|
| write_ptr | uint32_t | Transaction hash output buffer (32 bytes) |
| write_len | uint32_t | Output buffer size |
| read_ptr | uint32_t | Transaction data to emit |
| read_len | uint32_t | Transaction size |

**Return Value:**
- Success: `32` (hash size)
- Error: Negative error code

**Error Codes:**
- `OUT_OF_BOUNDS (-1)`: Memory out of bounds
- `TOO_SMALL (-4)`: Buffer too small
- `PREREQUISITE_NOT_MET (-9)`: etxn_reserve() not called
- `EMISSION_FAILURE (-11)`: Transaction validation failed
- `TOO_MANY_EMITTED_TXN (-13)`: Reserved count exceeded

**Transaction Requirements:**
- Account: Must match Hook owner
- Sequence: 0
- SigningPubKey: 0x00...00
- sfEmitDetails: Required (generated by etxn_details())
- LastLedgerSeq: Must be current ledger + 1 to + 5
- Signature: Not set

## etxn_burden

Get the burden value for emitted transactions.

```c
int64_t etxn_burden();
```

**Parameters:** None

**Return Value:**
- Success: Burden value (`otxn_burden() * etxn_reserve count`)
- Error: Negative error code

**Error Codes:**
- `PREREQUISITE_NOT_MET (-9)`: etxn_reserve() not called
- `FEE_TOO_LARGE (-10)`: Overflow

---

## etxn_fee_base

Calculate the base fee for an emitted transaction.

```c
int64_t etxn_fee_base(uint32_t read_ptr, uint32_t read_len);
```

**Parameters:**
| Name | Type | Description |
|------|------|-------------|
| read_ptr | uint32_t | Transaction data pointer |
| read_len | uint32_t | Transaction size |

**Return Value:**
- Success: Base fee (in drops)
- Error: Negative error code

**Error Codes:**
- `OUT_OF_BOUNDS (-1)`: Memory out of bounds
- `PREREQUISITE_NOT_MET (-9)`: etxn_reserve() not called
- `INVALID_TXN (-37)`: Failed to parse transaction

---

## etxn_details

Generate the sfEmitDetails field.

```c
int64_t etxn_details(uint32_t write_ptr, uint32_t write_len);
```

**Parameters:**
| Name | Type | Description |
|------|------|-------------|
| write_ptr | uint32_t | Output buffer pointer |
| write_len | uint32_t | Output buffer size (116-138 bytes required) |

**Return Value:**
- Success: Number of bytes written
- Error: Negative error code

**Included Fields:**
- sfEmitGeneration (4 bytes)
- sfEmitBurden (8 bytes)
- sfEmitParentTxnID (32 bytes)
- sfEmitNonce (32 bytes)
- sfEmitHookHash (32 bytes)
- sfEmitCallback (20 bytes, optional)

**Error Codes:**
- `OUT_OF_BOUNDS (-1)`: Memory out of bounds
- `TOO_SMALL (-4)`: Buffer too small
- `PREREQUISITE_NOT_MET (-9)`: etxn_reserve() not called
- `FEE_TOO_LARGE (-10)`: Burden calculation overflow

---

## etxn_reserve

Pre-reserve the number of transactions to emit.

```c
int64_t etxn_reserve(uint32_t count);
```

**Parameters:**
| Name | Type | Description |
|------|------|-------------|
| count | uint32_t | Number to reserve (1-255) |

**Return Value:**
- Success: count value
- Error: Negative error code

**Error Codes:**
- `TOO_BIG (-3)`: count > 255
- `TOO_SMALL (-4)`: count < 1
- `ALREADY_SET (-8)`: Already reserved

**Important:** Must be called before emit().

---

## etxn_generation

Get the generation of an emitted transaction.

```c
int64_t etxn_generation();
```

**Parameters:** None

**Return Value:**
- Generation value (otxn_generation() + 1)

## etxn_nonce

Generate a unique nonce for an emitted transaction.

```c
int64_t etxn_nonce(uint32_t write_ptr, uint32_t write_len);
```

**Parameters:**
| Name | Type | Description |
|------|------|-------------|
| write_ptr | uint32_t | Output buffer pointer (32 bytes) |
| write_len | uint32_t | Output buffer size |

**Return Value:**
- Success: `32`
- Error: Negative error code

**Error Codes:**
- `OUT_OF_BOUNDS (-1)`: Memory out of bounds
- `TOO_SMALL (-4)`: write_len < 32
- `TOO_MANY_NONCES (-12)`: Called 256 or more times

**Usage Example:**
```c
etxn_reserve(1);

uint8_t emitdet[138];
int64_t emitdet_len = etxn_details(SBUF(emitdet));

// Build transaction
uint8_t txn[256];
// ... include sfEmitDetails ...

uint8_t hash[32];
emit(SBUF(hash), SBUF(txn));
```
